# Java + Agent 面试一月复习计划

Oct 6, 2026 · @meteorzhong

## 总览

30 天（10/10 – 11/8）覆盖知识图谱全部 44 个核心节点和 73 个重点节点（了解级不单独排期），分四个阶段：Java 核心 → Spring 与中间件 → 分布式、工程化与 Agent 基础 → Agent 深入与冲刺。每日表中 ★ 为核心、☆ 为重点；“题库题数”是在 面试题与知识图谱.html 的知识图谱里点击当天节点能跳转到的关联题总数。

**取舍原则**：图谱中 *核心* 节点必须能讲到源码/原理级；*重点* 节点能讲清是什么、为什么、怎么用；*了解* 节点只准备一句话定义，时间不够直接跳过（如 HBase、ClickHouse、Service Mesh、Tree-of-Thoughts、Google ADK）。

**每日节奏（全职备考，每天约 7 小时，每周第 7 天半天复盘）**

| --- | --- | --- |

**间隔复习规则**

- 每道题首次学完记为 D0，在 D+1、D+3、D+7 各闭卷口述一次；三次都答顺就移出清单，任一次卡壳就重置为 D0。
- 每周第 7 天抽测本周及以前的内容，正确率低于 80% 的模块，下周每天早间多分 15 min 给它。
- 题卡用一个 Markdown 表或 Anki 即可，每题一行：题目 · 首学日期 · 下次复习日期 · 是否卡壳。

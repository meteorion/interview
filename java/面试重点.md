# Java 开发工程师面试重点

按章节编排为自测面试题。版本差异以项目使用的 JDK/组件为准。

## 一、Java 基础

1. **类型与面向对象**
   - 基本类型和包装类型有什么区别？自动装箱/拆箱何时发生，Integer 缓存范围有什么边界？
   - Java 为什么说是值传递？
   - 重载与重写、抽象类与接口有什么区别？组合和继承如何取舍？`static`、`final` 和访问修饰符分别有什么作用？
2. **Object 契约与字符串**
   - `==` 与 `equals()` 有什么区别？为什么重写 `equals()` 时必须遵守相等对象具有相同 `hashCode()` 的约定？
   - `String` 为什么不可变？字符串常量池和 `intern()` 如何工作？什么场景选 `StringBuilder` 或 `StringBuffer`？
3. **异常与资源管理**
   - `Error`、受检异常和非受检异常有什么区别？异常何时应处理、封装或继续抛出？
   - try-with-resources 如何关闭资源？`AutoCloseable` 有什么作用，关闭异常如何处理？
4. **泛型、反射与代理**
   - 什么是泛型擦除？它对运行时类型检查和重载有什么影响？
   - 如何用 PECS 解释 `extends` 读、`super` 写？
   - 反射和注解通常用于什么场景？
   - JDK 动态代理与 CGLIB 的实现方式和限制有什么不同？
5. **SPI、序列化与 IO**
   - SPI 如何发现服务实现？线程上下文类加载器解决什么问题？JDBC、Dubbo 如何使用这类机制？
   - `serialVersionUID` 和 `transient` 有什么作用？序列化版本不兼容会怎样？JSON 与 Protobuf 如何取舍？
   - 字节流和字符流有何区别？BIO/NIO、Buffer/Channel/Selector 分别是什么？字符集错误会造成什么问题？
6. **常用语言特性与数值**
   - Java 8、9–17、21 分别有哪些常用特性？Lambda/Stream、record、sealed class、模式匹配、Sequenced Collections 适合什么场景？
   - 虚拟线程与结构化并发是什么，支持状态如何？它们适合解决什么问题？
   - 浮点数为什么有精度问题，`BigDecimal` 如何正确构造、舍入和比较？

## 二、集合框架

1. **集合体系与迭代**
   - `Collection` 与 `Map` 有什么区别？List/Set/Queue、Iterator、`Comparable` 和 `Comparator` 分别解决什么问题？
   - fail-fast 在什么情况下触发？为什么它只是尽力检测而不是线程安全保证？
2. **List 与队列**
   - `ArrayList` 的底层结构、随机访问和扩容机制是什么？迭代器何时 fail-fast？与 `LinkedList` 的查找和插入成本如何比较？
   - `ArrayDeque`、`PriorityQueue`、`BlockingQueue` 分别适合什么场景？如何按访问、插入和阻塞需求选型？
3. **HashMap 与其他 Map**
   - HashMap 如何计算桶位置、处理冲突和扩容？JDK 7/8 有什么差异？JDK 7 并发扩容为何可能形成链表环？HashMap 为什么不是线程安全的？
   - `LinkedHashMap`、`TreeMap`、`WeakHashMap` 分别有什么特点？
   - ConcurrentHashMap 如何从 JDK 7 分段锁演进到 JDK 8 CAS/桶级同步？读操作、计数和复合操作如何保证正确性？
4. **Set 与常见陷阱**
   - HashSet、LinkedHashSet、TreeSet 底层如何实现？它们分别依据什么规则去重或排序？
   - `Arrays.asList()` 和 `subList()` 有什么视图/固定长度特性？不可变集合有哪些修改限制？

## 三、并发编程

1. **线程基础与 JMM**
   - Java 线程有哪些状态？中断如何工作？`sleep`、`wait`、`notify`、`join` 对锁和线程状态有何影响？守护线程是什么？
   - JMM 的原子性、可见性、有序性分别指什么？happens-before 如何约束线程间读写？
2. **synchronized、volatile 与锁**
   - `synchronized` 如何实现互斥和可见性？Monitor、锁竞争、锁消除/粗化是什么？偏向锁在不同 JDK 中有何变化？
   - `volatile` 保证什么、不保证什么？双重检查锁为什么需要它？内存屏障起什么作用？
   - `ReentrantLock` 与 `synchronized` 在中断、超时、公平性和 Condition 上有何区别？
3. **CAS、AQS 与并发工具**
   - CAS 如何工作？什么是 ABA，`AtomicStampedReference` 如何解决？高竞争自旋有什么代价，`LongAdder` 适合什么场景？
   - AQS 的 state、等待队列、独占/共享模式分别是什么？`CountDownLatch`、`CyclicBarrier`、`Semaphore` 有何区别？
   - `ReadWriteLock` 和 `StampedLock` 适合什么场景？读写锁升级有什么限制？
4. **线程池与异步编程**
   - `ThreadPoolExecutor` 有哪些参数和任务处理步骤？队列、拒绝策略如何工作？为何先入队、队满后扩线程？`Executors` 默认池有什么风险？
   - 如何根据任务类型、吞吐和延迟配置线程池？`allowCoreThreadTimeOut` 和 `ScheduledThreadPoolExecutor` 有何作用？
   - `CompletableFuture` 如何组合任务、传播异常和取消？阻塞 IO 为什么不宜占用公共池，何时应指定 Executor？
5. **ThreadLocal 与上下文传递**
   - ThreadLocalMap 为什么使用弱引用 key？强引用 value 如何残留？线程池任务结束后为何要在 `finally` 中 `remove()`？
   - ThreadLocal 为什么不会自动跨线程？MDC、用户和链路上下文如何传递，如何避免线程复用造成串数据？
   - `CompletableFuture` 的每个异步阶段如何传递和清理上下文？任务装饰器或 TTL 如何解决？
6. **并发队列、虚拟线程与排障**
   - `ArrayBlockingQueue`、`LinkedBlockingQueue`、`SynchronousQueue` 在容量和背压上有何区别？`wait` 为什么必须循环检查条件？
   - CopyOnWriteArrayList 和 ConcurrentLinkedQueue 分别适合什么场景？各自有什么限制？
   - 虚拟线程适合什么任务，为什么不能加速 CPU 密集计算？使用时还需考虑哪些资源和限流问题？
   - 结构化并发和 Scoped Values 解决什么问题，版本状态如何？Scoped Values 与 ThreadLocal 有何区别？
   - 如何用 `jstack` 定位死锁？死锁四个必要条件是什么，如何用锁顺序或超时预防？

## 四、JVM

1. **运行时内存与对象**
   - JVM 运行时区域有哪些、各自存什么？堆 OOM、栈溢出、元空间 OOM 和直接内存 OOM 有何区别？
   - 对象如何创建、布局和访问？动态生成类或类加载器无法卸载时，为什么会导致元空间增长？
2. **类加载与执行**
   - 类加载有哪些阶段？双亲委派解决什么问题？SPI、Tomcat 为什么需要打破或绕过它？
   - 解释执行、JIT、热点识别、C1/C2 分层编译和逃逸分析分别是什么？标量替换/锁消除是否意味着对象一定在栈上分配？
   - 未逃逸、方法逃逸、线程逃逸如何区分？哪些因素会影响逃逸分析优化效果？
3. **垃圾回收**
   - 什么是 GC Roots 和可达性分析？强/软/弱/虚引用有何区别？标记清除、复制、标记整理和分代算法分别适合什么情况？
   - 什么是安全点和 STW？三色标记如何产生漏标，屏障、卡表和记忆集如何解决？
   - Serial、Parallel、CMS、G1、ZGC 如何取舍？G1 Region/Mixed GC 和 ZGC 染色指针/读屏障解决什么问题？相关能力如何随 JDK 版本变化？
4. **诊断与调优**
   - `jps`、`jcmd`、`jstat`、`jmap`、`jstack`、JFR、MAT、Arthas 分别适合诊断什么问题？
   - 如何结合 GC 日志、堆转储和线程栈排查 OOM、泄漏、频繁 GC 和 CPU 高？调优后如何验证效果？

   - 如何读取 `EXPLAIN` 的 type/key/rows/Extra？`Using filesort`、`Using temporary` 表示什么？如何结合慢 SQL 和数据分布优化？

3. **日志与崩溃恢复**

4. **SQL 与数据库工程**
   - 如何使用 JOIN、聚合、子查询和窗口函数？表设计、深分页和批量操作有哪些注意点？

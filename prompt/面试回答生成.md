# 面试回答生成提示词

复制以下提示词，将【】中的内容替换为自己的题目；不确定的项目可以留空。

```text
你是一位资深 Java 技术面试官兼面试教练。我会给你一道面试题，你要生成一份可以直接背下来口述的"标准面试回答"。

【题目】（必填）
【岗位与级别】：默认 高级 Java 后端
【回答时长】（可选）：留空则按题型自动取值；也可指定 30 / 60 / 90 秒，按压缩规则处理
【侧重点】（可选）：如"偏原理"、"偏实战"、"要能接住追问"；留空则均衡处理

全程使用中文。

## 一、先判断题型，再决定重心

| 题型 | 回答重心 |
|---|---|
| 概念题 | 是什么 + 为什么存在 + 一个反例 |
| 机制题 | 链路顺序 + 关键结构 + 触发条件 |
| 对比题 | 先定比较维度，再逐项，最后给判断 |
| 边界题 | 何时不成立 + 原因 |
| 场景与排障题 | 现象 → 分层 → 工具 → 根因 → 验证 |

对应关系不必写进输出，只用于决定内容取舍。

| 题型 | 口述版字数 | 目标时长 | 必须覆盖的层 |
|---|---|---|---|
| 概念题 | 120—180 | 30—45 秒 | 结论、为什么存在、一个反例 |
| 机制题 | 200—280 | 50—70 秒 | 结论、链路、触发条件、例外 |
| 对比题 | 220—300 | 55—75 秒 | 比较维度、逐项、判断、不适用场景 |
| 边界题 | 150—220 | 40—55 秒 | 何时不成立、原因、正确做法 |
| 场景与排障题 | 260—350 | 60—90 秒 | 现象、分层、工具、根因、验证 |

字数可上下浮动 15%，但不得为了凑字数省略该题型必须覆盖的层。

**时长冲突处理**：如果我在【回答时长】里给了具体值，以我的为准，但压缩按这个顺序砍——先砍实践与案例，再砍对比与取舍，最后砍细节参数；机制链和根因不能砍。指定时长低于该题型下限时，宁可超出 10 秒，也不要把机制讲断。

如果题目过宽（如"讲讲 JVM"），先用一句"我按 X 理解"把范围收窄到 3 个子问题以内，再按收窄后的范围回答。

## 二、输出结构（顺序固定）

### 1. 口述版（主产物）
- 字数与时长取上方对应题型的区间，连续段落，不分点、不换行罗列
- 内部顺序：**结论 → 机制 → 例外 → 取舍 →（一句实践）**
- 第一人称，允许"我会先""取决于""这里要注意"
- 禁止"首先 / 其次 / 最后"这类书面连接词
- 目标：正常语速讲完，落在该题型的目标时长内

### 2. 短版
≤120 字，只保留结论 + 核心机制，用于电梯陈述或时间紧张时。

### 3. 展开版
分层给要点，供被追问时取用，每层 1—3 条：
- 机制链：按执行顺序列关键步骤
- 关键结构或参数：涉及的数据结构、字段、默认值
- 触发条件：什么时候走这条路径
- 例外：什么情况下不成立
- 对比取舍：替代方案与代价

### 4. 追问预判
条数按题型：概念题 3 条、机制题 4—5 条、对比题 4 条、边界题 3 条、场景题 4—5 条。每条写成"追问方向 → 一句话应答要点"，优先覆盖最可能被追的两三个方向。

### 5. 常见错误答法
1—2 条，每条注明错在哪一层（只有结论、混淆概念、答非所问、超出题目范围）。

### 6. 记忆锚点
一行关键词串，用箭头连接，便于复述整段逻辑。

## 三、内容要求
- 每一层都必须给出因果，不能只有结论
- 存在版本差异的（JDK、GC、Spring Boot、Spring 版本）必须标注"以版本为准"
- 不得编造数字、性能数据、参数默认值；不确定时用"通常""多数情况下"，并说明取决于什么
- 术语首次出现给英文，之后用中文
- 对比题必须先建立比较维度，再逐项比较

## 四、禁止事项
- 禁止把口述版写成文档式罗列或小标题堆叠
- 禁止超出规定字数
- 禁止只讲正常路径、不提例外
- 禁止给出没有因果支撑的结论
- 禁止复述题目本身当开场

## 五、输出前自检（内部执行，不输出）
- 口述版是否落在该题型的目标时长内，或已按压缩规则处理
- 结论、机制、例外、取舍四层是否齐全
- 是否存在编造的数字或参数
- 追问预判是否覆盖了最可能的两个方向
```

## 使用方法

1. 复制上面代码块里的内容，把 `【题目】` 换成要练的题。
2. 想练短答就填 `【回答时长】30 秒`，会按压缩规则先砍实践与取舍层，机制链保留。
3. 生成的「口述版」直接读出声，卡壳的地方就是没真正理解的地方。

## 填写示例

```
【题目】HashMap 的容量为什么必须是 2 的幂？
【岗位与级别】高级 Java 后端
【回答时长】45 秒
【侧重点】要能接住追问
```

预期会得到：一段 45 秒的口述稿（结论 → 位运算等价取模 → 只对 2 的幂成立 → 空间换效率），加上分层展开、追问预判（为什么用扰动函数、扩容后元素位置怎么变、初始容量怎么定）和常见错误答法。
